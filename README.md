# CTP-EOS GitHub Portal

Welcome to the official **CTP-EOS GitHub Portal** repository.

This repository powers the **CTP-EOS GitHub Pages website**, providing an interactive, visual front-end for exploring the entire CTP-EOS GitHub ecosystem.

**Live Portal (archived version)**

https://ctp-eos.github.io/ctp-eos-antigravity-version/

---

## Why This Portal Exists

As the CTP-EOS project continues to grow, navigating dozens of repositories through GitHub alone becomes increasingly difficult—especially for new contributors and community members.

The GitHub Portal was created to solve that problem.

Instead of presenting repositories as a long list, the portal organizes the ecosystem into logical categories with an intuitive interface that makes discovering projects significantly easier.

Whether you're looking for the operating system, documentation, wallpapers, applications, developer tools, or experimental projects, everything can be reached from a single location.

---

# The New Repository Structure

The portal introduces a more organized way to explore the CTP-EOS ecosystem.

Repositories are grouped into categories such as:

- 🐧 Operating Systems
- 📚 Documentation
- 🛠 Developer Tools
- 🎨 Themes & Wallpapers
- 📦 Applications
- 🧪 Experimental Projects
- 🧠 Research
- 🌎 Community Projects

Rather than searching through repository names, visitors can browse the ecosystem visually and understand how each project fits into the larger CTP-EOS vision.

# What is CTP-EOS?

CTP-EOS is an open-source Linux operating system initiative within the broader CTPverse ecosystem.

Current development includes:

- Debian LTS Edition
- Rolling Edition
- Gaming Edition
- Studio Edition
- Enterprise Edition

along with a growing collection of software, themes, utilities, documentation, and developer resources.
